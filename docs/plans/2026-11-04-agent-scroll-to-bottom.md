# 聊天回到底部按钮

已确认方案：按钮位于输入框正上方、水平居中，使用圆形向下箭头。离开消息底部至少 80px 显示，回到底部后隐藏；按钮不占布局高度，不影响项目选择与输入框高度。

实现沿用消息区现有的底部跟随阈值，不改变历史阅读时暂停自动跟随的行为。点击平滑滚动，减少动态效果时直接定位；隐藏按钮不接收点击或键盘焦点，支持 Enter / Space 激活。颜色使用共用主题变量。

验证：扩展 `xt-client/frontend/tests/history.browser.test.mjs`，检查底部隐藏、上翻显示、相对输入框的居中位置、键盘返回和减少动态效果，保留原有历史分页与滚动位置回归。桌面 WebView2 的实际显示仍需人工验收。
