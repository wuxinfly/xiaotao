# Agent 结果气泡展开实施计划

**目标：** 执行中两行 Markdown 气泡，回答完成后同一气泡展开，思考区收起，正文底部保留紧凑统计摘要，可打开完整过程。

**实现：** Go 保留 message_delta 与 answer_end，删除控制工具、二次回答请求及 answering 状态；React 用稳定 runId 节点承载草稿与最终回答，气泡高度过渡、轨迹折叠，历史直接完整展示。失败与取消保留真实状态和已有文字，不伪装完成。

**步骤：**
1. 修改 service.go 与流式回归，验证无控制工具、一次生成、工具上下文与取消。
2. 修改 AgentPage.tsx、agent.css 和 API 类型，实现 Markdown、展开、底部摘要和滚动跟随。
3. 更新回答浏览器回归，覆盖节点连续、两行高度、Markdown、完成、停止、失败、历史、窄窗口与减少动态效果。
4. 同步 README、架构和旧方案状态；执行前端构建、浏览器测试、go test ./...、go vet ./... 与规则检查。

**边界：** 不保留 begin_answer/answering 的兼容分支，不做旧数据迁移。不改变业务工具历史配对及其他在途改动。后续过程高度、图标入口与真实请求/速度摘要调整见 [过程轨迹与结束摘要](2026-11-07-agent-trace-summary.md)。
