# Agent 已保存项目

**目标：** 项目分类可以单独保存；项目下会话全部删除后分类仍保留，只有用户手动删除项目时才从项目列表移除。

**行为：** 项目记录保存路径、显示名和创建/更新时间到当前环境 Agent SQLite 的 `saved_projects` 表。项目列表合并已保存项目与有会话的目录，按标准化路径去重。删除项目只移除保存分类，不删除会话、消息、执行记录或项目文件夹；剩余会话仍按原项目路径分组，没有剩余会话时项目消失。项目重命名同步保存记录和现有会话元数据。默认工作目录不保存。

**前端：** 项目弹窗提供“保存项目”和“使用这个项目”，两者分开：前者写入分类并同步侧栏，后者只选择工作目录。项目视图的已保存项目显示删除入口，删除前确认，文案明确会话回到“最新”。空项目仍显示项目组，可在该项目下新建会话；项目重命名同步空项目的侧栏名称。

**验证：**

- Go 回归：保存后创建会话复用显示名；删除该目录全部会话后项目仍保留；重命名持久化；删除项目只移除保存记录，会话路径和显示名不变，项目文件夹保留。
- 前端隔离回归：`node --test tests/project-actions.browser.test.mjs`，覆盖只选择不误标保存、空项目重命名同步、键盘顺序、删除确认、接口删除与项目组保留。
- 构建与检查：`npm run build`、`go test ./...`、`go vet ./...`。

**边界：** 不导入另一环境的项目记录；目录被删除时当前列表仍返回保存记录，后续新建会话会按现有目录校验报错；桌面壳实际交互待人工验收。
