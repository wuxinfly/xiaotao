# 最小客户端实现计划

日期：2026-10-31。基于已确认总体方案执行。

目标：Windows Go EXE 启动独立服务，通过 WebView2 或浏览器打开相同页面。本阶段不实现安装器和模型转发。

1. 建立 Go 模块、嵌入式页面、健康检查。
2. 命名互斥量保证服务单实例，动态回环端口避免冲突，运行状态写用户目录。
3. 拉起隐藏服务并等待就绪；独立窗口使用 WebView2，缺失时回退浏览器。
4. 配置原子保存；管理写操作校验同源。
5. 基础导航、真实服务状态、浏览器入口、明确退出。窗口关闭保留服务；托盘后续实现。
6. 测试接口、配置和跨源拒绝，构建后执行进程级冒烟验证，更新文档。
