# 小涛客户端阶段进度

日期：2026-10-31，2026-11-01 更新。阶段：基础壳、模型入口和 Agent 单任务闭环已形成。

## 已完成

- Go 独立本地服务与启动入口，动态回环端口、健康检查、同数据目录单实例、配置与运行状态独立存储。
- 系统 WebView2 桌面窗口，浏览器也能访问同一套页面；不携带浏览器运行时，不主动写应用注册表项。
- 自绘标题栏，拖动、四边及四角缩放、最小化、最大化/还原、顶部双击切换。
- 保留原生窗口样式并隐藏系统非客户区，恢复系统窗口过渡效果；用户已确认效果。
- 关闭收起到托盘，双击恢复，右键提供打开、浏览器打开、退出；菜单向上展开，用户已确认。
- React + TypeScript + Vite 前端，海洋深色主题，水滴精灵图标用于页面、窗口、托盘和 EXE。
- 顶部居中导航“小涛 Agent / 模型”，模型下拉包含仪表盘、账号与配额；展开收起、箭头和选项具有动效，支持点击及键盘操作和减少动态效果设置。
- 根据用户要求，Web 页面清理为设计基础版：移除临时卡片、占位介绍、服务调试信息、预览页脚和配置表单；保留导航、空内容区和窗口交互。底层服务及托盘未清理。
- 交互与动效规则写入 xt-client/AGENTS.md 和总体方案。
