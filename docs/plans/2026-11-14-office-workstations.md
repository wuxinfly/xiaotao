# 办公室工位、角色动作和日夜

**目标：** 小涛有固定独立桌，工位跟随成员变化，空闲时可走动，开始工作时坐回自己的工位。

**实现：** 从现有项目快照分配工位和动作；GLB 提供可复用的桌椅、关节和窗景，Three.js 在运行时组装。日夜跟随客户端主题。

**验收：**

1. 仅有小涛的项目显示一张独立桌。添加、移出成员只增减对应工位；人数超出首排后继续排布并扩展视角。
2. 空闲成员轮流沿通道散步、回桌坐下；工作、排队或待确认时优先回桌。切换项目时清除原项目的工位和动作。
3. 标题栏切换主题即时改变窗外和室内光源；不重建场景或重置相机。系统开启“减少动态效果”时，角色直接坐于工位。
4. 验证桌椅和角色资产、工位增减、主题切换、任务打断空闲动作和原有办公室交互；验证构建不覆盖桌面运行实例。
