# 项目侧边栏操作

项目名保留折叠操作，移除项目三角箭头。悬停或键盘聚焦时显示横向三点菜单及方框笔形新会话图标，触屏始终显示。新会话先解析目录，再清空当前草稿并预填项目，不立即创建数据库会话。

菜单复用 Popover，提供项目显示名重命名和资源管理器打开。重命名复用公共模态框，同目录历史会话的显示名在 SQLite 事务内一起保存，不改目录、消息及排序；项目有运行会话时拒绝。资源管理器入口校验目录后调用 Windows ShellExecute，不拼接命令。

验收：前端构建、Go 测试与 vet；`node --test tests/project-actions.browser.test.mjs tests/history.browser.test.mjs` 使用隔离 API 验证隐藏/聚焦按钮、菜单、项目预填、重命名刷新恢复、减少动态效果与原有虚拟列表。Go 测试验证重启持久化、多会话一致性、历史与排序保留、其他项目隔离和运行中拒绝。

桌面壳实际 hover 观感及资源管理器弹出仍需人工验收。此次为局部产品交互，没有需沉淀的通用规则候选。

样式修正：项目行图标按钮显式清除全局按钮 padding，固定 26×26，操作间隔 2px、右侧留白 4px，防止图标溢出及悬停底色尺寸不一致；浏览器回归检查尺寸、图标居中和边界。

项目名称按钮 hover 保持透明，去除左侧独立底色，仅保留项目整行悬停底色与右侧操作反馈。

补充修正：ocean-tech.css 的 `.agent-session-list button:hover` 优先级覆盖了名称透明样式。将该规则限定为 `.agent-session-select:hover`，避免影响项目按钮；回归直接断言鼠标悬停名称时最终计算背景为透明。
