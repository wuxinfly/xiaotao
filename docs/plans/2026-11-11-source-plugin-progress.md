# 模型来源插件实施进度

范围：插件底座与 Trae，其他平台暂缓。

已实现本地目录安装、启停、stdio 进程隔离、版本/入口检查、加密凭据、稳定模型 ID、统一网关和 Agent 目录、Trae 独立进程入口、令牌导入与当前环境旧账号显式迁移、模型发现、聊天、配额与签到。使用与第三方接入说明见 `docs/plugins/README.md`。

模型设置已支持搜索、仅显示已选、全选/全不选，以及按上游 ID 添加手动条目。保存后，Agent 和网关共用选中目录；未保存过设置的插件仍默认开放全部发现的模型。离线验收覆盖持久化、取消选择后不可路由、显式空列表和手动 ID 原样路由。

已支持插件发起的 Trae 浏览器授权、多账号排序、逐账号配额与签到，以及保留状态的本地更新。首位账号用于聊天与模型目录，聊天的续期和请求使用同一账号。旧单账号状态会保留为列表第一项。尚未实现卸载、自动账号故障转移、旧模型引用批量映射；同插件串行执行。真实 Trae 账号与 Windows 桌面壳留待本地验收，不能声称第 3、4 部分全部完成。
