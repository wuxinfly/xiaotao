# 当前轮执行过程展开时机

用户确认：执行中的当前轮保持过程展开，本轮结束后再自动折叠。

实现沿用 AgentPage 的用户消息轮次分组，以当前轮边界和会话忙碌状态判断过程是否仍在运行，不再仅判断过程是否是最后一个条目。因此工具完成后继续思考、输出回复时仍保持展开。执行期间忽略摘要、外部点击及 Escape 的收起请求；结束后恢复历史过程的手动开关。完成、失败和停止均走忙碌状态结束的同一分支。沿用 Portal 定位与展开收起动画。

验证：前端构建、流式过程/历史过程/头像三个隔离浏览器回归、go test ./...、go vet ./... 以及规则检查通过。流式用例覆盖已完成工具与后续文字、提前收起尝试、结束收起和再次展开。浏览器测试串行运行，避免测试服务端口及并行浏览器干扰。桌面壳人工验收仍待完成。

文档同步：客户端 README 增补行为及回归命令；架构与 API 无变化。该需求属于本功能行为，未形成新的跨任务开发约定，不新增规则候选。
