# 小涛 Agent 单任务内核实施记录

日期：2026-11-01。

状态：首版实现与本地验证完成；真实账号、桌面文件夹选择和真实项目代码任务待人工验收。

## 目标

把 Agent 页面从占位页变成可工作的单任务闭环：选择项目与模型，小涛读取代码、修改文件、运行验证，并允许用户停止。底层采用 Go 自研运行内核，模型调用复用现有本地代理，不依赖第三方 Agent 宿主。

## 实现

### 后端

- 新增 `internal/agent`：项目目录边界、会话类型、文件与命令工具、模型 HTTP 客户端和工具循环。
- 新增管理接口：模型列表、项目校验、任务创建/列表/读取、消息 SSE、停止任务。
- 会话持久化到用户数据目录 `agent/sessions/`；遗留 `running` 会话重启后明确标为中断。
- 模型请求经本地 `/v1/chat/completions`，沿用账号、模型目录和用量统计。
- 首版最多 40 个模型/工具回合；工具结果保留调用 ID 并完整回传模型。

### 桌面

- WebView2 窗口绑定 `xtPickFolder`，调用 Windows 原生文件夹选择框。
- 浏览器输入仍可直接粘贴绝对路径；文件夹选择不作为浏览器能力承诺。

### 前端

- Agent 页重做为工作台：任务历史、项目/模型上下文、消息、执行进度和停止操作。
- 首屏默认进入 Agent；模型页保留原有导航。
- 无模型时明确引导账号接入；不伪造模型可用状态。
- 桌面宽屏三栏，较窄视口收起右侧设置栏，手机宽度单栏显示。
- 交互支持键盘发送、焦点反馈、减少动态效果和任务运行状态反馈。

### 文档

- 新增 `docs/architecture/xt-client-agent.md`，记录边界、取舍、工具限制和验收缺口。
- 更新客户端总体方案与 README 的 Agent 状态。

## 已知限制

- 工具执行不是操作系统级强隔离。路径检查、明显危险命令拦截和超时只降低误操作风险。
- 文件夹选择器在 WebView2 桌面窗口中的实际交互尚未人工确认。
- 真实模型账号完成实际代码修改的完整任务尚未人工验收。
- 逐 token 模型输出、完整 Skill 发现、伙伴和工作流未实现。
- 当前工具运行在本地服务进程上下文，取消不能保证外部程序派生出的所有子进程都被终止。
