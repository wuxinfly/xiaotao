# 来源模型目录

账号与配额页在来源标题旁提供“查看模型”，在原页展开目录，沿用深海主题。按需加载并保留展开内容，以支持连续展开和收起动画；隐藏时 inert，减少动态效果设置下取消过渡。

同一来源可切换账号，使用同源 POST /api/proxy/models 的 accountId 参数；复用代理模型目录逻辑并返回 live/builtin/merged/cached 来源，不修改默认账号或既有聚合响应。完整调用 ID 使用来源前缀，支持复制、刷新、加载和错误反馈。

验收：各来源展开目录；切换账号；复制完整 ID；Trae 实时目录失败时显示内置目录；刷新失败可重试；键盘访问；快速展开收起；减少动态效果；桌面及浏览器入口。真实账号权限与调用结果需实际账号验收。
