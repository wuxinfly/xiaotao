# 客户端启动窗口优化

用户确认：启动动画用于遮挡初始化白屏，切换其他应用时不应持续遮挡或在启动完成时抢焦点。

实现：去除封面 WS_EX_TOPMOST；当前 WebView 库在 Embed 前主动 ShowWindow，使用当前 UI 线程的临时 CBT 钩子，仅匹配 webview 类，在构造期间阻止激活，构造结束立即解除。封面作为主窗口的 owned window，仅覆盖小涛自身；主窗口保留正常显示与可见性消息，让 WebView2 正常加载和绘制。前端挂载后等待字体、当前图片解码及 150ms，发送 ready。原生窗口和 WebView2 默认背景统一为 #071723。

2026-11-04 调整为约 2.5 秒播完，帧进度按经过时间追赶，最短展示时间同为 2.5 秒，15 秒无 ready 时兜底交接。交接先显示主窗口再销毁封面，仅封面仍在前台时激活主窗口；否则放到后台且不激活。托盘恢复和重复启动仍支持显式激活已完成启动的窗口。

验收：启动期间切换其他应用，确认封面可被覆盖、交接不抢焦点；停留在封面时正常进入主界面；首屏延迟时不提前出现白色主窗口；15 秒兜底后可查看页面；关闭到托盘后正常恢复；正式与 UAT 并行互不影响。

回归原因：首版拦截 SHOWWINDOW、隐藏初始化，只检查窗口隐藏，没有加载真实前端。用户反馈动画结束后长期停留、兜底交接后主窗口空白，浏览器正常。补充真实前端 ready 检查后，旧实现稳定超过 7 秒无法就绪；保留窗口正常显示与可见性消息、使用 owned 封面遮挡后，通过真实前端及 chrome 正式交接逻辑，约 5 秒完成整个测试，早于 15 秒兜底。

验证：回归测试加载实际构建前端，经真实 WebView2 和 chrome 完成 ready→动画等待→交接；断言主窗口可见、不成为前台、正常交接早于兜底。独立临时副本 `build.ps1 -Verify` 构建通过，启动验证 EXE 使用独立数据目录，实际桌面截图与可访问性文本确认 Agent 页面内容正常、动画已关闭。慢加载、故障兜底及正式/UAT 并行交互仍待专项验收。未递增版本或替换正式 EXE。

规则检查：补充待确认候选 `desktop-startup-render-verification`，要求启动生命周期修改覆盖真实前端加载和交接；不自动应用。
