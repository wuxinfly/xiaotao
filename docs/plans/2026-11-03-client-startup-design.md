# 客户端启动窗口优化

用户确认：启动动画用于遮挡初始化白屏，切换其他应用时不应持续遮挡或在启动完成时抢焦点。

实现：去除封面 WS_EX_TOPMOST；当前 WebView 库在 Embed 前主动 ShowWindow，使用当前 UI 线程的临时 CBT 钩子，仅匹配 webview 类，在构造期间拦截显示和激活，构造结束立即解除。主窗口隐藏加载页面；前端挂载后等待字体、当前图片解码及 150ms，发送 ready。原生窗口和 WebView2 默认背景统一为 #071723。

保留最短 3.9 秒动画等待，15 秒无 ready 时兜底交接。交接先显示主窗口再销毁封面，仅封面仍在前台时激活主窗口；否则放到后台且不激活。托盘恢复和重复启动仍支持显式激活已完成启动的窗口。

验收：启动期间切换其他应用，确认封面可被覆盖、交接不抢焦点；停留在封面时正常进入主界面；首屏延迟时不提前出现白色主窗口；15 秒兜底后可查看页面；关闭到托盘后正常恢复；正式与 UAT 并行互不影响。

自动验证覆盖真实 WebView 窗口在构造期间保持隐藏、前台不变以及解除拦截后可显示。完整桌面动画、慢加载、故障兜底及双环境交互仍需人工验收。

验证结果：真实 WebView 隐藏/不激活测试、Go 全量测试、go vet、规则检查通过；前端构建通过。`build.ps1 -Verify` 在原目录因运行中依赖文件占用失败；独立副本打包被同期主题修改引用的缺失文件 `frontend/src/shallow-sea.css` 阻塞，未修改其他工作来绕过。未递增版本或替换正式 EXE。
