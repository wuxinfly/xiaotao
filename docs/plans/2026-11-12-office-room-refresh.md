# 办公室首屏改版

首屏以海底观察舱为主：员工工位在左，项目资料架在右。点击员工打开对话弹窗，点击执行者打开当前任务。右下角悬浮按钮展开项目切换、刷新、任务列表和运行信息。窄窗口把资料架排在工位下方。

React 复用现有弹窗和轮询接口。Go 在返回资料架和任务产物时核对文件是否仍是项目内的普通文件，保留历史记录及文件预览的失效提示。

验收：检查首屏、员工对话与交接、任务列表与详情、资料预览、键盘关闭、窄窗口和浅海主题；用 Go 测试覆盖移动或删除文件后列表更新，并确认任务及历史产物记录保留。

验证结果：办公室与导航浏览器回归（合成 API）、前端检查、Go 全量测试、Go vet 和 UAT 验证构建通过。真实模型与 WebView2 中的交互仍待手动验收。
