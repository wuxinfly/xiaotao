## 小涛客户端 v1.3.1

本次更新重点完善 Agent 协作、模型接入和多账号使用体验。

### 主要更新

- 新增多会话并行、会话引用、历史分页和多段选中文字引用。
- 新增 MCP 工具管理、内置浏览器工具和活动详情展示。
- 新增本地 Skills 扫描、启用与禁用。
- 支持 WorkBuddy 原生登录、Qoder 活动打卡和 Trae 缓存用量核对。
- 优化模型倍率、账号额度、WorkBuddy 工具兼容和桌面启动体验。
- 增加浅海 / 深海主题切换。

### 下载与使用

下载 `xiaotao-v1.3.1.exe`，放到固定目录后双击运行。

### 运行环境

- Windows x64
- 需要 Microsoft Edge WebView2 Runtime

### 说明

- 当前提供直接运行的 EXE，不是安装向导。
- 本次安装包未做代码签名，Windows 可能显示安全提示。
- 升级前请退出正在运行的旧版客户端。
